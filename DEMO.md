# Larust Winning Live Demo

## Stage Line (Open With This)
**"Larust is where feedback becomes verifiable evidence."**

## Core Narrative Arc
Run one continuous chain:
**Create -> Collect -> Verify -> Triage -> Export**

## 0:00 - 0:25 Hook (Landing + category clarity)
- Open `/`.
- Point at the hero + live vault preview.
- Say exactly:
  - "Most feedback tools collect text. Larust collects evidence."
  - "Respondents never need a wallet."
  - "Admins still get wallet-backed ownership and control."

## 0:25 - 1:00 Form Studio Moment (show product depth fast)
- Go to `/create`.
- Verify admin session if needed from header.
- Choose **Bug Report** template.
- Highlight:
  - reorder controls,
  - helper copy,
  - required toggle,
  - sensitive toggle.
- Publish and open the public link.
- Say: "The same schema drives both creation and public rendering."

## 1:00 - 1:45 Public Intake Moment (frictionless + trustworthy)
- On `/f/[slug]`, call out trust strip:
  - Walrus evidence,
  - sensitive field count,
  - media evidence slots.
- Fill a realistic issue:
  - rich description,
  - dropdown + checkbox + rating + URL,
  - screenshot + video upload.
- Submit and open `/f/success`.
- Read the receipt:
  - submission ID,
  - Walrus blob reference,
  - architecture assurance tiles.
- Say: "This receipt is the proof anchor, not just a thank-you page."

## 1:45 - 2:35 Operations Moment (why teams adopt this)
- Go to `/dashboard` then `/dashboard/forms/[id]`.
- Show:
  - command metrics,
  - realistic seeded data by template,
  - filters (status/priority/rating/date/keyword).
- Open one submission:
  - evidence ref (Walrus blob),
  - payload,
  - asset links,
  - notes/status/priority actions.
- Export JSON + CSV.
- Say: "We’re not just collecting responses; we’re operating a feedback command center."

## 2:35 - 3:00 Win Condition (judge takeaway)
- State clearly:
  - "Walrus is canonical for evidence payloads and assets."
  - "Sensitive sections are isolated and Seal-encrypted when configured."
  - "Owner-only APIs enforce secure admin workflows."
- Final line:
  - **"Larust delivers feedback ops with cryptographic accountability."**

## Backup Talking Points (if asked)
- Why this wins:
  - Distinct product category: feedback vault, not generic forms.
  - End-to-end live path with real Walrus references.
  - Security narrative is visible in the UI, not hidden in docs.
- If asked about Seal dependencies:
  - Client and server integration paths are implemented.
  - Full decrypt requires real network config + session key flow.

## Delivery Tips (presenter)
- Keep pace: never dwell on setup longer than 10 seconds.
- Use one realistic bug report narrative from start to end.
- Repeat "verifiable evidence" three times during the demo.
